## 설치

```
pip install https://github.com/hyeongdongE/ai-supervisor/releases/download/v0.1.0b1/ai_supervisor-0.1.0b1-py3-none-any.whl
```

필요한 것: Python 3.10+, git, [Claude Code CLI](https://docs.claude.com/en/docs/claude-code)
