# AI Supervisor  — **Closed Beta (pre-release)**

> **이 판은 0.1.0b1, Closed Beta 시험판입니다.** 정식판이 아닙니다.
> 참가자 2명과 함께 「전문가 팀 방식이 값을 하는가」를 확인하는 중이고,
> 그 답에 따라 구조가 바뀔 수 있습니다. 업무에 그대로 의존하지 마십시오.

목표만 주면 **필요한 전문가 Agent 를 모아** 일을 시킵니다. Claude Code 를
대체하지 않고 그 위에서 돕니다.

```bash
pip install aisupervisor

cd ~/my-project     # 당신의 git 저장소
supervisor
```

알아야 할 것은 위 두 줄뿐입니다. `init` 도, `--repo` 도, 작업 종류도 치지
않습니다. Supervisor 가 목표를 읽고 **무슨 일인지 · 혼자 할지 팀을 부를지 ·
누가 붙을지**를 정하고, 그 이유를 먼저 보여 줍니다.

## 무엇이 다른가

- **검증된 Agent 만 씁니다.** 처음 실행하면 이 기계의 격리된 임시 저장소에서
  Agent 를 **실제로 돌려 보고**, 통과한 것만 일에 넣습니다. 다른 기계의 검증
  결과를 그대로 믿지 않습니다.
- **작업마다 권한이 다릅니다.** 기획·설계는 읽기만, 구현자는 쓰기까지,
  시험은 실행까지. 선언하지 않은 도구를 쓰려 하면 막습니다.
- **말이 아니라 증거로 판정합니다.** 바뀌었다는 파일이 정말 바뀌었는지,
  통과했다는 시험이 **우리가 돌려도** 통과하는지 직접 확인합니다.
- **뒤 Agent 가 앞 Agent 를 그냥 믿지 않습니다.** 어긋난 것을 발견하면 그
  단계로 되감아 다시 만듭니다.

## 지원 환경

| | |
|---|---|
| Python | **3.10 이상** |
| 함께 필요한 것 | `git`, [Claude Code CLI](https://docs.claude.com/en/docs/claude-code) (`claude` 명령) |
| 실측한 OS | **Linux 만** |
| **Windows** | **아직 실측하지 않았습니다.** 순수 파이썬 휠(`py3-none-any`)이고 배포 코드에 POSIX 전용 호출이 없어 설치는 될 구조지만, 저희가 돌려 본 적은 없습니다 |
| macOS | 실측하지 않았습니다 (Linux 와 같은 조건으로 봅니다) |
| 외부 의존성 | **0** — Python 표준 라이브러리만 씁니다 |

Claude Code CLI 사용량은 **사용자 본인 계정에서** 나갑니다. 실측: 작은 수정
30~60초·$0.2 안팎, 큰 기능 하나에 팀이 붙으면 **30~40분·$10 이상**.

## 알려진 한계

- **브라우저에서의 화면 동작 확인은 사람 몫입니다.** 서버가 준 HTML 은
  확인하지만 클릭 이후는 자동 시험이 아닙니다
- **자동 재작업(되감기)은 한 실행에 2회**까지입니다. 넘으면 남은 지적은
  기록만 되고 반영되지 않습니다
- **팀 방식은 느리고 비쌉니다.** 같은 앱을 혼자 344초·$1.86 에, 팀은
  2562초·$10.86 에 만들었고 **둘 다 동작했습니다.** 작은 일은 알아서 혼자
  처리하지만, 큰 일에 팀을 붙이는 판단이 늘 옳다고 보지 않습니다
- 시험이 없는 저장소에서는 완료를 판정할 수 없습니다 (`--test-command` 로
  알려 주시면 이어서 판정합니다)
- 저장소 여러 개를 한 번에 다루지 못합니다

## 이번 판에서 **하지 않는** 일

- **운영 배포(`deploy.production`)**
- **비밀값 접근(`secret.read`)**
- **되돌리기 어려운 마이그레이션 · 파괴적 운영 작업**

Agent 가 이런 권한을 요구하면 **실행 전에 멈추고** 사람에게 알립니다.
승인해서 진행하는 경로는 이번 판에 없습니다.

## 소스 코드와 기록

- **코드는 당신의 기계를 떠나지 않습니다.** Supervisor 는 서버가 없고 계정도
  로그인도 없습니다. 다만 Claude Code CLI 자체는 Anthropic API 와 통신하며,
  그 범위는 평소 `claude` 를 쓰실 때와 **똑같습니다**
- 실행 기록은 `~/.supervisor/` 안에만 쌓입니다
- **기록에 소스 코드가 들어가지 않습니다** — 바뀐 파일의 **개수와 확장자만**
  남고 경로도 내용도 남기지 않습니다. 목표 문장은 흔한 비밀값 모양
  (토큰·비밀번호)을 지운 뒤 남습니다
- 저희가 기록을 자동으로 가져가지 않습니다. **직접 보내 주실 때만** 봅니다
  (`supervisor report --out 파일`)

## 바뀐 코드는 커밋되지 않습니다

`git diff` 로 직접 보고 판단하십시오. Supervisor 는 커밋하지 않습니다.
